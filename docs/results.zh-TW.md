# 結果與退役

Alpaca 模擬帳戶，起始資金 $100,000，期間為 2026-04-14 至 2026-10-09 收盤（共 120 個交易日）。最終淨值、現金與 24 檔未平倉部位已於 2026-10-10 與 Alpaca 核對。

| 指標 | 結果 |
|------|------|
| 最終淨值 | $107,064.60（**+7.06%**） |
| SPY，同一期間（調整後收盤價） | **+12.68%** |
| 機器人減去 SPY | **-5.62 個百分點** |
| 對 SPY 的迴歸（日資料，n=124） | beta 0.417、alpha 年化 +3.9%、**t = 0.35** |
| Alpha 95% 信賴區間 | 年化 [-18.3%, +26.1%]（殘差波動率 7.80%／年） |
| 夏普值（無風險利率 = 0） | 機器人 1.55，SPY 2.08 |
| 最大回撤（日收盤價） | 機器人 -3.64%，SPY -4.49% |
| 交易 | 290 筆買入、310 筆賣出；賣出勝率 41.0%；獲利因子 1.20 |
| 各出場類型損益 | 移動停損 +$15,857；強制停損 -$12,610；AI 出場 -$1,345；AI 減碼 -$117；訊號賣出 +$2,656 |
| 在 t=2 下證明 alpha != 0 所需的實盤時間 | 約 16 年 |

Alpha 的估計值在統計上與零無法區分：信賴區間橫跨年化 -18.3% 到 +26.1%。

資料說明：

- 最終狀態：現金 $8,494.42；24 檔持倉，市值 $98,570.18，於退役時凍結。這是模擬帳戶，因此持倉仍會持續按市價重估；上述數字是正式的最終快照。
- 缺口：2026-06-30 至 2026-07-13 是舊 Pi 的中斷（7 個交易日，持倉維持不動），2026-08-26 則沒有執行。
- 2026-10-09 以降級狀態執行（agy 額度用完，退回 Gemini flash-lite）。排除該日後結果為 +6.27%，對照 SPY 的 +12.01%，主要結論不變。
- LLM 用量：6,939 次分析師呼叫（67,295 筆標的分析）與 27,489 次 LLM 出場複核。已記錄的計費 Claude 花費為 $0.49（412 次 Haiku 呼叫，2026-08-17 至 2026-10-09），另有開始記錄之前的估計花費約 $34。

## 退役原因

擁有者於 2026-10-10 的決定：

1. **這個研究問題，不管跑多久都不會有實用的答案。** 要證明 alpha 存在，需要約 16 年的實盤運行。
2. **績效落後買入持有 SPY 5.6 個百分點**，beta 也比較低；風險調整後同樣落後（夏普值 1.55 對 2.08）。
3. **LLM 這條路只有維護成本，沒有研究回報。** 它把擁有者主帳號的 Gemini 額度吃光（約每日 320 次呼叫），供應商鏈也一路降級（Hugging Face 額度、agy 額度、DeepSeek 代理被封鎖的風險）。

## 學到什麼

- 後備如果跟主要路徑共用同一個計費管道，就不算後備。
- 要對 LLM 降級發警報，不能只對徹底失敗發警報。
- 時區與 cron 的陷阱是真的。
- 在說「先跑下去看看」之前，先做檢定力分析。
- 有四種機制讓機器人偏向不作為（失敗時一律 HOLD、關卡採 fail-closed 等）。
